🎓 **Preskool – School Management System**

Preskool is a custom backend system built for a school to manage students, teachers, classes, subjects, attendance, payments, and administrative statistics.

This solo internship project was designed to improve efficiency, simplify admin tasks, and provide a full-featured web management system using PHP.

🚀 **Key Features**
🏫 **Student & Teacher Management**

CRUD operations for students, teachers, classes, and subjects

Search functionality to quickly find records

Upload and manage student/teacher pictures

Track attendance and payments

🔐 **Authentication & Security**

Login via Google and Facebook OAuth

Password recovery workflow

Email notifications for updates and alerts

📄 **Reports & Stats**

Generate PDF reports for students, teachers, and payments

Statistics page for attendance, payment tracking, and performance

🧩 **System Architecture**
| **Component**         | **Description**                                 |
| --------------------- | ----------------------------------------------- |
| **Frontend**          | PHP, HTML, CSS, JavaScript                      |
| **Backend**           | PHP                                             |
| **Database**          | MySQL                                           |
| **Authentication**    | Google/Facebook login, password recovery        |
| **Email Integration** | Notifications and alerts                        |
| **PDF Reports**       | Generate and save admin/student reports         |
| **Statistics**        | Visualize attendance, payments, and class stats |

👤 **Personal Contribution**

Designed and implemented full CRUD for all tables

Built search functionality and PDF reports

Integrated Google and Facebook login

Implemented password recovery and email notifications

Developed statistics and admin dashboards

Handled file uploads for student and teacher images

🎯 Project Goal

The goal of Preskool was to provide a centralized, efficient, and user-friendly backend system to manage all school operations, reduce administrative overhead, and provide real-time insights for teachers and admins.
